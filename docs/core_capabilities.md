# Core Capabilities — Visual Risk AI

Visual Risk AI (VRCI) combines stochastic simulation models, biological circadian algorithms, deterministic compound growth engines, and conversational agentic intelligence into a living digital twin tailored to each user's unique life stage.

---

## 1. Visual Risk Copilot & Conversational Agent

The **Visual Risk Copilot** (`/chat`) is an autonomous conversational agent directly connected to the user's live profile, recent biometric logs, academic records, and financial ledger.

### 4-Stage Agentic Reasoning Pipeline
When a user submits a prompt (via text or Web Speech voice dictation), the system orchestrates a 4-stage problem-solving sequence:

```
[ Step 1: Goal Definition ]
        │ Decomposes prompt into optimization targets (capital friction, habit shifts, task injection)
        ▼
[ Step 2: Telemetry Gathering ]
        │ Queries real database records (sleep debt, surplus, screen time, active milestones)
        ▼
[ Step 3: Multi-Criteria Analysis ]
        │ Computes circadian alertness windows (08:30–11:30), 5-year CAGR, and elasticity indices
        ▼
[ Step 4: Strategic Execution Plan ]
        │ Renders structured Markdown tables and dispatches 1-click execution proposals
```

### Real-Time Reasoning Disclosure (`<think>`)
The Copilot discloses its complete mathematical logic, boundary checks, and intermediate formulas inside collapsible `<think>` blocks. Users can verify assumptions, CAGR rates, inflation offsets, and circadian alertness curves in real time.

### Voice Input (Speech-to-Text)
Integrated Web Speech API dictation allows hands-free query submission with auto-capitalization and punctuation formatting.

## 2. Interactive Multi-Action Execution Engine

Unlike passive chatbots, every recommendation generated by the Visual Risk Copilot includes an actionable, 1-click execution card:

| Action Identifier | Execution Behavior | Database & State Impact |
| :--- | :--- | :--- |
| **`add_multiple_tasks`** | Injects an optimized daily block schedule directly into the Daily Task Planner (`/planner`). | Creates scheduled task records with priority tags and categories. |
| **`add_task`** | Schedules a single time-block with duration, start time, and category. | Appends entry to the user's active task queue. |
| **`purchase_impact`** | Evaluates financial friction against emergency fund milestones and 5-year compounding opportunity cost (8% CAGR). | Generates decision matrix and updates variance projections. |
| **`simulate_what_if`** | Sandboxes lifestyle tradeoffs (e.g. studying 5 more hours vs sleeping 30 mins less). | Computes focus and vitality elasticity without modifying live profile. |
| **`wealth_forecast`** | Triggers a 500-run Monte Carlo volatility trial with percentile curves. | Calculates retirement goal attainment probability. |
| **`update_settings`** | Commits profile parameter modifications (income, expenses, sleep targets) with one tap. | Persists updated baseline attributes to the `User` database table. |
| **`log_habit`** | Commits biometric sleep, workout, or screen time telemetry directly to the database. | Appends `HabitRecord` and instantly updates `/analytics` metrics. |
| **`log_study`** | Logs academic subject deep work blocks and retention scores. | Appends `StudyRecord` and refreshes study intelligence charts. |

## 3. Interactive Settings & Telemetry Control Center (`/settings`)

The Settings Center provides 5 reactive configuration panels:

1. **Persona & Role**: Interactive cards for 5 life-stage personas (Student, Professional, Freelancer, Entrepreneur, Retiree) with live telemetry previews.
2. **Biometrics & Daily Routine**: Sliders for sleep baseline (4h–10h), study targets (0h–40h/wk), screen time caps (1h–12h), and a 7-day workout frequency selector.
3. **Financial Telemetry**: Real-time monthly surplus calculator, net worth tracker, 5-year compounding forecast preview, and milestone tracker.
4. **AI Intelligence Engine**: Collapsible `<think>` reasoning toggle, Monte Carlo trial depth selector (250/500/1000 runs), and proactive scheduling sensitivity.
5. **System & Data**: Dark/Light theme toggle, 1-click JSON telemetry export, onboarding wizard reset, and database factory reset.

## 4. Financial Twin & Monte Carlo Forecasting (`/wealth`)

- **500-Iteration Stochastic Volatility Modeling**: Models portfolio growth using Geometric Brownian Motion with log-normal asset returns ($\mu = 8\%$, $\sigma = 15\%$) and annual inflation indexing ($2.5\%$).
- **Percentile Confidence Bands**: Computes 10th percentile (Bear Market), 50th percentile (Median Trajectory), and 90th percentile (Bull Market) horizons.
- **Adaptive Multi-Scale Visualizations**: Recharts engine with dynamic Y-axis scaling that gracefully handles student allowances in hundreds of dollars to venture equity and retirement reserves in millions.
- **Intelligent Prediction Cache**: Caches heavy simulation runs to deliver sub-50ms render latency.

---

## 5. Decision Sandbox & What-If Simulator (`/simulator`)

- **Side-by-Side Scenario Modeling**: Real-time evaluation of competing lifestyle paths (Scenario A vs. Scenario B).
- **Multi-Variable Tradeoff Engine**: Analyzes tradeoffs between sleep duration, screen time, study intensity, and monthly savings.
- **Biological Feedback**: Computes Health Score, Cognitive Focus Score, and Burnout Risk.
- **1-Click Adoption**: Seamlessly applies winning scenario parameters directly to your live profile.

---

## 6. Universal Habit Analytics & Daily Reflection Cache (`/analytics`)

- **Grouped Correlation Visualizations**: Multi-axis telemetry charts comparing Sleep vs. Focus, Screen Time vs. Mood, and Exercise vs. Vitality.
- **Automated Noon AI Reflection Cache**: Automatically evaluates habit logs at 12:00 PM local time to generate fresh daily reflections with automatic cache invalidation.

---

## 7. Robust Authentication & Session Security (`/users`)

- **Unified Multi-Identifier Login**: Seamless authentication supporting either registered email address or username.
- **Dual Uniqueness Verification**: Enforces database-level uniqueness across both `users.username` and `users.email`.
- **Auto-Recovery**: Seamlessly links existing user accounts if a user attempts to sign up with an existing email.
- **Session Ownership Isolation**: Chat threads, message histories, and action executions enforce strict `user_id` verification (403 Forbidden on mismatch).
